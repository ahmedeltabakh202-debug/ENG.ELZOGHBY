# مقايسة — إصلاح وصيانة السيارات

تطبيق ويب (PWA) لإنشاء وحفظ ومشاركة مقايسات إصلاح السيارات.

## الملفات

| ملف | الوصف |
|-----|--------|
| `index.html` | التطبيق الرئيسي |
| `manifest.json` | إعدادات PWA |
| `sw.js` | Service Worker للعمل دون اتصال |
| `icon-*.png` / `logo.png` | أيقونات ولوجو التطبيق |
| `favicon.png` / `apple-touch-icon.png` | أيقونات المتصفح والآيفون |

## التشغيل محلياً

افتح المجلد على خادم بسيط (المتصفحات تطلب HTTPS أو localhost للـ PWA):

```bash
npx serve .
# أو
python3 -m http.server 8080
```

ثم افتح: `http://localhost:8080`

## الرفع على GitHub Pages

1. أنشئ مستودع جديد على GitHub.
2. ارفع كل محتويات هذا المجلد إلى جذر المستودع (أو مجلد `docs`).
3. من Settings → Pages اختر المصدر `Deploy from a branch` والفرع `main` والمجلد `/ (root)`.
4. بعد دقائق التطبيق يعمل على:
   `https://YOUR_USER.github.io/REPO_NAME/`

## التفعيل (للإدارة)

- زر «لوحة التفعيل» مخفي.
- افتح لوحة الإدارة بالضغط على كلمة **مقايسة** (في شاشة التفعيل أو الشارة في الهيدر).
- كلمة مرور الإدارة: `tabakh95`
- من اللوحة تولّد أكواد تفعيل مرتبطة بكود الجهاز.

## تثبيت التطبيق

زر **⬇️ تثبيت التطبيق** يظهر بجانب زر الوضع النهاري/الليلي.  
بعد التثبيت يختفي الزر تلقائياً.
